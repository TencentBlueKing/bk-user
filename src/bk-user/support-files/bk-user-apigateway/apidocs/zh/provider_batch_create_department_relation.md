### 描述

批量创建部门父子关系（数据提供方专用接口）

### 路径参数

| 参数名称          | 参数类型 | 必选 | 描述      |
|---------------|------|----|---------|
| data_source_id | int  | 是  | 数据源 ID |

### 请求参数

| 参数名称              | 参数类型   | 必选 | 描述                          |
|-------------------|--------|----|---------------------------------|
| relations         | array  | 是  | 部门关系列表，最大 100 条              |
| relations[].id    | string | 是  | 部门唯一标识（数据源内）                |
| relations[].parent | string | 是  | 父部门唯一标识，null 表示设为根部门        |

### 请求示例

```json
{
    "relations": [
        {"id": "dept_a", "parent": "company"},
        {"id": "dept_b", "parent": null}
    ]
}
```

### 响应示例

```
HTTP 204 No Content
```
