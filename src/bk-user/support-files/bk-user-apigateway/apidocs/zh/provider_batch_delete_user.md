### 描述

批量删除用户（数据提供方专用接口）

### 路径参数

| 参数名称          | 参数类型 | 必选 | 描述      |
|---------------|------|----|---------|
| data_source_id | int  | 是  | 数据源 ID |

### 请求参数

| 参数名称  | 参数类型  | 必选 | 描述                      |
|-------|-------|----|-----------------------------|
| ids   | array | 是  | 用户唯一标识列表，最大 100 条 |

### 请求示例

```json
{
    "ids": ["emp_001", "emp_002"]
}
```

### 响应示例

```
HTTP 204 No Content
```
