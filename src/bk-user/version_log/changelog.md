## V3.0.1
### 新增
- **【登录安全】** 新增“同一用户多会话禁止连接”功能，以增强会话安全。
- **【个人中心】** 新增了个人中心支持绑定企业微信/微信公众号的功能。

### 优化
- **【人员选择器】** 全面优化了新版组织架构人员选择器组件，提升了人员搜索、选择的交互体验。
- **【数据源同步】** 优化了数据源同步能力。HTTP 数据源新增支持 APIGateway 认证方式，同时支持增量同步，提升了数据源同步时的用户体验。
- **【安全防护】** 优化了内置管理员临时链接、密码有效期等登录安全逻辑，降低了通过内置管理员账密进行安全爆破的风险。
- **【安全防护】** 新增“用户敏感字段”保护方案，对指定字段进行脱敏或权限控制。
- **【组织架构】** 支持直接在租户节点下“添加子组织”，统一了多租户与单租户的操作体验。
- **【时区规范】** 引入全新的时区选择组件，并增强了对地理时区的校验逻辑。

### 修复
- **【数据源同步】** 修复了用户批量导入功能中未正确校验必填字段的问题。
- - **【组织架构】** 修复了特定场景下租户内用户的部门组织路径计算或显示错误的问题。
- **【通知与同步】** 修复了本地身份源在发送通知时，邮件发送者校验缺失或错误的问题。
- **【组织架构】** 修复了页面修改组织名称后，组织名称显示异常的问题。
- **【全局】** 修复了 3.x 多租户模式下的测试问题若干。

## V3.0.0
### 新增
- **【多租户架构】** 全新支持 SaaS 化多租户管理，实现平台内不同租户间数据与配置的逻辑隔离。
- **【跨租户协同】** 新增跨租户协作策略配置能力，以适应集团型企业的复杂组织结构。
- **【组织与账号】** 引入全新的组织架构体系，支持灵活的部门树管理和拖拽调整。新增独立的“虚拟账号”功能模块，用于管理非实名/非员工类型的服务账号或临时人员。
- **【数据源与配置】** 增强数据源配置能力，支持多种外部身份源（IDP）的灵活接入与同步。新增用户属性字段的自定义配置功能。重新设计了平台管理员与租户管理员的权限模型。
- **【登录与认证】** 新增统一登录源管理功能，支持管理员为不同的用户数据源灵活配置独立的登录方式（如本地密码、企微扫码、OA 单点登录），实现异构账号体系的统一认证入口。
- **【安全审计】** 新增平台操作历史功能，完整记录管理员及用户在用户管理平台中的所有关键操作（如增删用户、修改权限、配置变更），为安全审计与事件追溯提供数据支撑。
- **【消息通知】** 新增消息通知配置功能，支持为账号激活、密码即将过期等场景，配置并自动通过邮件、短信等渠道向用户发送提醒，提升账号安全性与使用体验。
- **【Open API】** 推出全新的 Open API v3，重构了接口设计规范，提升与蓝鲸生态其他平台的集成能力。
- **【国际化】** 全站支持中英文语言切换。
